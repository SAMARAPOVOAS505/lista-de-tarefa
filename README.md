# Lista de Tarefas
## Descrição
- O projeto "Lista de Tarefas" é uma aplicação de gerenciamento de tarefas desenvolvida para ajudar os usuários a organizar e acompanhar suas atividades diárias. Originalmente implementado em JavaScript, este projeto foi reescrito em Java para explorar as funcionalidades do back-end e aprimorar o desempenho e a escalabilidade da aplicação.

## Tecnologias Utilizadas
### Front-End
- HTML: Utilizado para estruturar o conteúdo da aplicação, garantindo que as informações sejam apresentadas de forma clara e organizada.
- CSS: Aplicado para estilizar a interface da aplicação, proporcionando um design atraente e uma experiência de usuário intuitiva.
- JavaScript: Implementado para adicionar interatividade à aplicação, permitindo a manipulação dinâmica de elementos da página e a gestão das tarefas de forma eficiente.
### Back-End
- Java: Utilizado para o desenvolvimento do servidor e da lógica de negócios da aplicação. A escolha do Java visa oferecer robustez e escalabilidade, além de integrar de forma eficaz com o banco de dados.
- MySQL: Banco de dados relacional empregado para armazenar e gerenciar os dados das tarefas. O MySQL permite a persistência das informações e a execução de consultas complexas de forma eficiente.
## Funcionalidades
- Cadastro de Tarefas: Permite ao usuário adicionar novas tarefas à lista.
- Atualização de Tarefas: Oferece a opção de editar tarefas existentes.
- Conclusão de Tarefas: Permite marcar tarefas como concluídas.
- Remoção de Tarefas: Facilita a exclusão de tarefas da lista.
## Como Funciona
- Front-End: A interface é desenvolvida em HTML e estilizada com CSS, oferecendo uma experiência de usuário intuitiva. JavaScript é usado para capturar as interações do usuário e enviar dados para o servidor.

- Back-End: O servidor, desenvolvido em Java, processa as requisições recebidas do front-end, realiza operações de CRUD (Criar, Ler, Atualizar, Deletar) no banco de dados MySQL e retorna as respostas apropriadas para a interface do usuário.

- Banco de Dados: MySQL armazena as informações das tarefas e possibilita a realização de consultas para gerenciar os dados.

- Abra os arquivos HTML em um navegador para utilizar a aplicação.
## Conclusão
Este projeto ilustra a integração entre tecnologias de front-end e back-end, mostrando como a migração de uma aplicação originalmente em JavaScript para Java pode melhorar o desempenho e a escalabilidade. A escolha das tecnologias foi feita para explorar diferentes aspectos do desenvolvimento de software e oferecer uma solução robusta para gerenciamento de tarefas.
